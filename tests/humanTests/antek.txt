Jasne — oto prosta funkcja w Pythonie odwracająca pojedynczo połączoną listę:

```python
class Node:
def __init__(self, value, next=None):
self.value = value
self.next = next

def reverse_linked_list(head):
prev = None
current = head

while current:
nxt = current.next
current.next = prev
prev = current
current = nxt

return prev
```
